# 拼多多多多进宝：从零到拿到 4 个凭证

目标：拿到 `PDD_CLIENT_ID` / `PDD_CLIENT_SECRET` / `PDD_PID`，让 `shopping-mcp` 的拼多多适配器切到 live。

流程分两段：**先在开放平台建应用**，**再去多多进宝后台绑定并取推广位**。第二段不做的话，API 权限是空的——这是最常见的卡点。

> 下面步骤整理自社区实操文档（[拼多多开放平台申请及绑定多多进宝](https://www.kancloud.cn/taonote/heiheliebian/1061184)），平台页面会改版，**以你当下看到的页面为准**。

---

## 第一段：开放平台建应用（拿 client_id / client_secret）

1. 打开 <https://open.pinduoduo.com>，注册并登录（没有账号先注册）。
2. 同意开发者协议。
3. 开发者类型选 **第三方开发者**。
4. 身份类型选 **个人**（个人即可，不需要企业资质——这是三家平台里门槛最低的地方）。
5. 填写开发者信息 → 核对无误 → **提交审核**。
6. **等审核通过再继续**。没通过时创建应用的入口是灰的。
7. 控制台 → **我的应用 → 创建应用** → 应用类型选 **「多多客联盟」**。
8. 完善应用信息：
   - 回调地址：填 `https://www.pinduoduo.com` 即可（官网地址可不填）
   - PRD 文档：下载模板后**什么都不改**，直接导出 PDF 上传。目前是机器审核、自动通过。
9. 提交**安全扫描并发布**，测试账号填「无」。
10. 应用审核通过后，在应用详情页复制：
    - `client_id` → 填进 `.env` 的 `PDD_CLIENT_ID`
    - `client_secret` → 填进 `.env` 的 `PDD_CLIENT_SECRET`

## 第二段：多多进宝后台绑定（拿 PID + 开通 API 权限）

**跳过这段 = 调接口全部报权限错误。**

11. 打开 <https://jinbao.pinduoduo.com>（多多进宝）。入口是**「手机号免注册登录」**——填手机号 + 短信验证码，首次登录即自动完成注册，不用单独走注册流程。
12. 在页面上输入上一步的 `client_id`，把应用与多多客账号**绑定**。
13. 绑定成功后，多多客 API 权限才会挂到这个应用上。
14. 在多多进宝后台找**推广位管理**，创建或查看推广位，复制 **PID** → 填进 `.env` 的 `PDD_PID`。

然后跑凭证验证（会真的发一次请求，很便宜）：

```powershell
uv run python scripts\probe_creds.py
```

它会告诉你：
- 拼多多是否已经切到 `live`
- 如果失败，是**签名错误**、**权限不足**还是**PID 不对**（这三种报错长得不一样，脚本会把原始错误打出来）
- 成功时打印原始返回的字段名 + 归一化结果，用来核对字段映射

把 `probe_creds.py` 的输出贴给我，我按真实返回校准 `adapters/pdd.py` 的字段映射。

## 常见报错对照

| 报错关键词 | 含义 | 处理 |
|---|---|---|
| `sign` / 签名错误 | client_secret 填错，或多了空格/引号 | 重新复制，确认没有首尾空格 |
| `权限` / `permission` / `不支持的接口` | 第二段没做，或应用未发布 | 回步骤 11-13 绑定多多进宝 |
| `invalid pid` / `p_id` | PID 不对 | 在多多进宝推广位管理里重新取 |
| `client_id` 无效 | 应用还在审核中 | 等审核通过 |
