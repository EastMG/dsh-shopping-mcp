# 拼多多多多进宝：从零到拿到 3 个凭证

目标：拿到 `PDD_CLIENT_ID` / `PDD_CLIENT_SECRET` / `PDD_PID`，让 `shopping-mcp` 的拼多多适配器切到 live。

流程分三段：**资质入驻 → 建应用 → 多多进宝绑定**。第三段不做，API 权限是空的——这是最常见的卡点。

> **可信度标注**
>
> 三段都已实际走通。下面标注了和旧版社区文档不一致的地方。
>
> 平台会改版，以你当下看到的页面为准。旧版社区文档说的「开发者类型选第三方开发者 / 应用类型选多多客联盟」**已经不是当前界面的口径**。

---

## 第一段：资质入驻（审核通过才能建应用）

1. 打开 <https://open.pinduoduo.com>，手机号注册并登录。
2. 导航栏点 **控制台** → 左侧 **资质信息**。未入驻时页面显示「您还没有入驻开放平台，入驻完成后可使用完整功能」。
3. 点 **立即入驻**。这一步要选**两组**东西：

   | 选项组 | 选什么 | 说明 |
   |---|---|---|
   | 开发者角色 | **多多进宝推手** | 做导购/带货。另外四个（电商软件服务商、商家服务商、拼多多商家、快团团团长）都另有用途 |
   | 入驻组织资质 | **个人开发者** | 不需要营业执照；企业开发者要企业资质 |

   ⚠️ 页面红字：**「一个主体只能入驻一次，请谨慎选择入驻资质」**——不可逆，别手滑。

4. 点 **下一步**，进入个人开发者填表页。需要准备：

   | 字段 | 要求 |
   |---|---|
   | 认证业务 | 下拉多选，当前只有「多多进宝推手」一项，勾上 |
   | 开发者身份证类型 | 中国大陆居民身份证（默认已选） |
   | 上传身份证件像 | **人像面 + 国徽面**，两张照片 |
   | 开发者姓名 | 与身份证一致 |
   | 开发者身份证件号 | 18 位 |
   | 证件有效期 | 起止日期（长期有效也要填） |
   | 联系邮箱 | 常用邮箱 |
   | 手机号 | 用于接收短信验证码 |
   | 图形验证码 | 页面上的 4 位字符 |
   | 短信验证码 | 点「获取验证码」后填 |

5. 全部填完 → **提交** → 等审核。
6. 提交后等审核。**实测：提交后状态直接变成「您提交的资质申请已通过」**，审核很快。

## 第二段：进多多进宝「开发者中心」拿 client_id / client_secret

> **实测纠正**：入驻通过后，开放平台控制台里**只有**两个入口——「个人中心 → 账号管理 / 资质信息」和「开发者角色」页签。**没有「我的应用 / 创建应用」**。旧文档里"在控制台创建应用"的说法，对「多多进宝推手」角色不成立。
>
> 创建应用的入口在**多多进宝后台**导航栏的 **开发者中心**（`jinbao.pinduoduo.com`）。
>
7. 打开 <https://jinbao.pinduoduo.com> 并登录。会弹「手机号免注册登录」——手机号 + 短信验证码，首次登录即自动注册。
8. 点导航栏 **开发者中心**，按页面提示创建应用。
9. 拿到 `client_id` / `client_secret` → 填进 `.env` 的 `PDD_CLIENT_ID` / `PDD_CLIENT_SECRET`。

## 第三段：取推广位 PID

10. 多多进宝后台 → **我要推广 / 推广管理** → 推广位管理。
11. 创建或查看推广位，复制 **PID** → 填进 `.env` 的 `PDD_PID`。

> 旧文档里"把 client_id 绑定到多多客账号"这一步，在官网首页已找不到对应说明。因为应用本身就是从多多进宝的开发者中心创建的，可能不再需要单独绑定——登录确认后再定。

## 实测补充：和旧文档不一致的地方

| 环节 | 实测 |
|---|---|
| 资质审核 | 提交后**立即通过**，无等待期 |
| 应用创建入口 | 入驻通过后，「开放管理」菜单才出现（之前完全看不到）。路径：开放管理 → 应用管理 → 应用列表 → 创建应用 |
| 应用类型 | 「多多客联盟」在列表里显示为**可创建**（仅多多进宝推手角色可见） |
| 应用审核 | 创建页 URL 带 `createAutoAudit=1`，提交后**直接「已上线」**，无需再走「开发测试应用 → 上线应用」两步 |
| client_id | 应用详情页明确展示 |
| client_secret | 默认打码，需点「查看」或「重置」 |
| 绑定 | 在 <https://jinbao.pinduoduo.com/third-party/rank> 输入 client_id → 确定，状态变为 `bindStatus=true`。不绑定调 API 会报「非多多客」 |
| PID 在哪 | **不是**「我要推广」下面，而是：推广者登记（`/promoter-audit`）→ **推广位管理** 页签。账号会自动带一个媒体登记（如「社交默认」）和一个默认推广位 |
| PID 格式 | `<多多客ID>_<数字>`，例如 `<多多客ID>_<推广位数字>` |
| 权限包 | 应用详情里可见「多多客权限包」「多多客工具权限包」等；推广位相关 API 为 `pdd.ddk.goods.pid.generate` / `pdd.ddk.goods.pid.query` |

**结论：从注册到 API 可用，一个人 1 小时内能走完，主要时间花在填实名表单上。**

## 第四段：授权备案（最容易漏，漏了所有 API 都报错）

拿到 PID 还**不能**直接调商品接口。拼多多要求「推手本人」做过一次**授权备案**，否则：

```
sub_code 60001 — 未传入已经授权备案过的相关参数(pid/custom_parameters)
```

注意这不是凭证错误，是**账号维度的授权**。官方 FAQ：<https://jinbao.pinduoduo.com/qa-system?questionId=218>

- 谁拿佣金谁备案 —— 就是将来收佣金的那个拼多多账号
- 一个拼多多账号最多备案给 5 个业务平台推手身份；一个推手只需备案一次
- 网页上**没有**备案表单，只能通过 API 走这两步：

```powershell
uv run python scripts\pdd_authorize.py          # 查状态；没备案就生成备案链接
uv run python scripts\pdd_authorize.py --status # 只查
```

脚本内部用：
- `pdd.ddk.member.authority.query` —— 查，`bind == 1` 即已备案
- `pdd.ddk.rp.prom.url.generate`（`channel_type=10`）—— 生成备案链接

拿到链接后**用你已登录拼多多的浏览器打开** → 点「确认授权」→ 再跑一次脚本，应显示 `bind=1`。

> 实测：备案生效有几十秒延迟，刚 `bind=1` 立刻调搜索可能仍返回 0 条，等一下再试。

## 第五段：goods_sign，不是 goods_id

拼多多已经停用 `goods_id` 入参（2026-10 实测）：

| 接口 | 传 goods_id 的报错 | 正确入参 |
|---|---|---|
| `pdd.ddk.goods.promotion.url.generate` | `40005 goods_id_list已下线，请使用goods_sign_list代替` | `goods_sign_list`（数组） |
| `pdd.ddk.goods.detail` | `40004 goods_id_list已下线` / `10002 goodsId与goodsSign为空` | `goods_sign`（**单数**） |

所以流程是：**搜索 → 从结果取 `extra.goods_sign` → 用它查详情 / 转链**。

`goods_id` 仍会出现在搜索结果里（用于拼商品页 URL），但不能作为接口入参。
本项目已把 `goods_sign` 放进归一化结果的 `extra.goods_sign`，直接传它即可。

## 填完之后

```powershell
cd <项目路径>
Copy-Item .env.example .env     # 第一次才需要
# 编辑 .env，填上面三个值
```

然后跑凭证验证（会真的发一次请求，很便宜）：

```powershell
uv run python scripts\probe_creds.py
```

它会告诉你：
- 拼多多是否已经切到 `live`
- 如果失败，是**签名错误**、**权限不足**还是**PID 不对**（这三种报错长得不一样，脚本会把原始错误打出来）
- 成功时打印原始返回的字段名 + 归一化结果，用来核对字段映射

把 `probe_creds.py` 的输出交给你的 AI 助手，让它按真实返回校准 `adapters/pdd.py` 的字段映射。

## 常见报错对照

| 报错关键词 | 含义 | 处理 |
|---|---|---|
| `sign` / 签名错误 | client_secret 填错，或多了空格/引号 | 重新复制，确认没有首尾空格 |
| `权限` / `permission` / `不支持的接口` | 第三段没做，或应用未发布 | 回步骤 11-13 绑定多多进宝 |
| `invalid pid` / `p_id` | PID 不对 | 在多多进宝推广位管理里重新取 |
| `client下线` / `clientId不正确`（code 10016） | 应用未上线或 client_id 错 | 确认应用已发布；核对 client_id |

## 另外两家

- **淘宝**：不需要备案域名或营业执照，但要注册淘宝联盟账户 + 完成推广者备案，流程见 [apply-taobao.md](apply-taobao.md)
- **京东**：入驻和凭证都能拿到，但基础权限包不含关键词搜索与导购媒体转链，对没有备案域名的个人工具不可行，见 [apply-jd.md](apply-jd.md)

建议先把拼多多跑通——它门槛最低，也不用域名。
