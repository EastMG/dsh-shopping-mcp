# 京东联盟：为什么 API 这条路走不通（实测记录）

2026-10-18 在真实账号（联盟ID 2038694924 / East-Morning）上走了一遍，结论先说：

> **能拿到 appkey，但转链接口必填的 `siteId` 只接受「已 ICP 备案的网站 / 已上架 APP / 真实流量媒体」，
> 个人自用的工具一个都不符合。所以京东 API 对本项目实际不可用。**

下面是逐条实证，留着以后有域名时复用。

## 卡住的地方：siteId

`jd.union.open.promotion.common.get`（转链）官方文档明确：

| 参数 | 必填 | 说明 |
|---|---|---|
| `materialId` | 是 | 推广物料 URL / 联盟商品 ID |
| **`siteId`** | **是** | 网站ID / APP ID / 流量媒体ID。**「接口禁止使用导购媒体id入参」** |
| `positionId` | 否 | 推广位 ID |
| `sceneId` | 是 | 1 或 2（2 需申请权限） |

而且：「投放链接的网址或应用必须与传入的网站ID/AppID**备案一致**，否则订单会判『无效-来源与备案网址不符』。」

### 三种能当 siteId 的媒体，各自要求（全部实测）

| 类型 | 创建要求 | 对本项目可行？ |
|---|---|---|
| **网站** | 网站地址必须是「**已完成备案的域名**」，另需填**工信部 ICP 备案号**；备案主体非本人时还要上传营业执照 + 授权书 | ❌ 没有备案域名 |
| **APP** | 需已上架的应用 | ❌ 没有 |
| **流量媒体** | 流量媒体类型（广告代理商 / 联盟流量）+ **推广平台**（巨量星图 / B站 / 小红书 / 微博…）+ **推广场景**（信息流 / 短视频 / 直播 / 图文）+ 类型（深海 / 种草） | ❌ 没有真实投放渠道，随便填属虚假申报 |
| 导购媒体 | 可创建 | ❌ **接口明确禁用导购媒体 ID 当 siteId** |

另外 `jd.union.open.goods.query`（关键词搜索）**不在基础权限清单里**，只有 `goods.jingfen.query`（京粉精选）、`goods.material.query`（猜你喜欢）等。

所以：即便凑出一个媒体拿到 `siteId`，个人工具也没法合规地产生"来源与备案一致"的订单。

## 如果以后有了备案域名，从这里继续

1. 推广管理 → 网站管理 → 创建网站：填域名（已备案）、ICP 备案号、网站类型、描述
2. 等审核通过 → 拿到 **网站ID**（= `siteId`）
3. 推广位管理 → 创建推广位 → 拿 **推广位ID**（= `positionId`）
4. 开放平台 → 应用管理 → 创建应用 → 拿 **Appkey / AppSecret**
5. 填 `.env`：`JD_APP_KEY` / `JD_APP_SECRET` / `JD_SITE_ID` / `JD_POSITION_ID`
6. 跑 `uv run python scripts\probe_creds.py --platform jd`

## 代码层面顺手修掉的两个坑

都在 `adapters/jd.py`，只有读真实文档才看得出来：

1. **响应 key 拼错的历史遗留**：京东网关返回的是 `jd_union_open_promotion_common_get_responce`
   —— 是 `responce`，不是 `response`。原来按 `_response` 拼必然匹配不到。现已两种拼写都认。
2. **业务错误藏在 result 里**：京东有时把 `{"code":..,"message":..}` 作为 JSON 字符串塞进
   `result`，原实现会当成"没有 data"，于是搜索返回空列表——表现为"没商品"，实际是报错。现已抛出。

## 结论

- 如果只是自用、又没有备案域名：**京东 API 暂无合规接入方式**，建议只用拼多多。
- 京东侧仍可手动操作：在联盟后台或京粉 APP 里点"一键推广"生成链接，只是不经过我们的 MCP。
